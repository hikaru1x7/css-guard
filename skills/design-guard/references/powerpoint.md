# PowerPoint

Open the intended PowerPoint app; include slides affected by shared masters/layouts. Measure Shape edges separately from TextRange2 BoundLeft/Top/Width/Height and compare text fit, centers and padding. Groups, table cells and rotated text need appropriate target-specific measurement; frames alone are insufficient.

Use the same app's Slide.Export PNGs or actual screen captures to check missing content, overlap and clipping. Animations require relevant intermediate-state checks. HTML/PDF alone does not certify PowerPoint. Adapter and sources: [document measurement](../../../docs/DOCUMENT-GUARDS.md).
