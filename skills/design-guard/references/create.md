# Creation only

- Decide necessary elements, information hierarchy and shared layout/styles before building. Remove meaningless decoration, containers and repeated explanation; group related elements. Retain units, comparison conditions and necessary context.
- Assign background, surface, text, accent and caption roles using approved colors or a verified reference. Consistent roles use consistent colors. Preserve boundaries and readability; small text targets 4.5:1 contrast and actual-size inspection.
- Diagrams express comparison, containment, sequence or responsibility with short, consistent labels. Put explanation in prose, narration or notes. Preserve required wording/conditions and do not impose diagram compression on prose-led documents.
- Compare the requested number of alternatives with identical content. Compare lines/fills/shadows for shape alternatives; hold geometry fixed for color alternatives. Video includes actual diagrams/footage, not just title frames. Do not impose one project's decoration on another.
- Inspect the first actual artifact as a whole; batch fixes to unnecessary elements, hierarchy, alignment, whitespace, text and colors. Remeasure and inspect affected areas until concrete issues are resolved. Improvement does not override user choices.
